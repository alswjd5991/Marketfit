# 대시보드 통계 분석 — 방법·검증·한계

코드: `src/features/analytics/` · 검증: `npm run test:analytics`

## 0. 원칙

1. **기준 미달이면 결과 대신 이유를 보인다.** 모든 분석에 최소 표본 기준이 있고, 못 넘으면 "분석 보류 — (이유)"를 표시한다.
2. **예측과 설명을 분리한다.** 예측에는 행사 전에 알 수 있는 정보만 쓴다.
3. **동시에 여러 개를 판정하면 다중비교를 보정한다**(Holm).
4. **인과 표현을 쓰지 않는다.** 관찰 자료이므로 "~하면 줄어든다"가 아니라 "~였던 날 평균 ~% 낮았다"로 쓴다.
5. **구현을 시뮬레이션으로 검증한다.** 정답을 아는 가상 데이터로 반복 실험해, 신뢰구간이 명목 수준만큼 정답을 포함하는지 확인한다.

## 1. 데이터

- 단위: 참가 완료 + 매출 기록이 있는 참가 1건(가게 × 행사).
- 여러 가게 기록을 함께 쓰는 분석(①③④)은 서버에서 service_role로 읽는다. 화면에는 요약값(계수·예측값·순위)만 보낸다.
- **합성 데이터 주의:** 현재 DB의 대부분은 기능 검증용 합성 셀러 30명의 기록이다. 합성 데이터는 `판매율 × 날씨계수(비 0.6, 흐림 0.85)`로 만들어졌다. 그래서 ③이 "비 온 날 −40%"를 찾아도 그건 발견이 아니라 **생성 가정을 정확히 복원한 것**이다. 화면과 보고서에 합성 비중을 반드시 함께 적는다. 발표에서는 이 점을 "알려진 효과를 복원하는 능력의 검증"으로 설명하는 것이 정확하다.

## 2. 모형

### ③ 매출이 달랐던 조건 — 가게 고정효과 회귀

$$\ln(\text{매출}_{ij}) = \alpha_i + \beta_1\,\text{흐림} + \beta_2\,\text{비} + \beta_3\,\text{실외} + \beta_4\,\text{주말포함} + \gamma_{\text{유형}} + \delta\ln(\text{일수}) + \varepsilon_{ij}$$

- **가게 고정효과 $\alpha_i$:** 가게마다 다른 가격대·상품·역량을 통째로 통제한다. 그래서 $\beta$는 "같은 가게가 조건만 달랐을 때"의 차이를 뜻한다.
- **효과 표시:** $100(e^{\beta}-1)\%$.
- **표준오차:** 행사 단위 군집-강건 **CR3(군집 잭나이프)**, 자유도 $G-1$.
  - 같은 행사에 나간 셀러들은 그날의 방문객 수 같은 충격을 공유하기 때문에 행사 단위로 묶는다.
  - CR1 대신 CR3를 쓰는 이유: "비 온 행사"처럼 설명변수가 소수 군집에 몰리면 CR1은 구간을 너무 좁게 잡는다. 실제로 시뮬레이션에서 CR1의 95% 구간 포함률은 88%였다(MacKinnon & Webb).
- **판정:** 여러 조건을 동시에 보므로 Holm 보정 $p<0.05$일 때만 "의미 있는 차이"로 표시한다.
- **기준:**
  - 기록 40건 이상, 행사 20곳 이상, 잔차 자유도 20 이상
  - 각 범주 5건 이상
  - 그 조건이 있을 때와 없을 때를 모두 겪은 가게 3곳 이상
- **제외 규칙:**
  - 기록 1건뿐인 가게: 가게 안에서 비교할 수 없음
  - 7일을 넘는 장기 행사: 셀러의 실제 출점 일수 기록이 없음
  - 날씨·실내외 미기재 기록
  - 기록이 적은 행사 유형: "기타 유형"으로 묶어 통제만 하고 해석하지 않음
- **한계:** 셀러가 날씨를 보고 참가 여부를 정하는 등의 선택 효과는 통제하지 못한다.

### ① 다가올 행사 예상 매출 — 예측 모형 + 경험적 베이즈

$$\ln(\text{매출}_{ij}) = \alpha_i + \beta_1\,\text{주말포함} + \beta_2\ln(\text{일수}) + \gamma_{\text{유형}} + \varepsilon,\quad \varepsilon\sim N(0,\sigma^2)$$

- **입력 변수:** 날씨·실내외는 미리 알 수 없어 넣지 않는다. 그 변동은 예측구간 폭에 그대로 반영된다.
- **가게 효과의 축소 추정:**
  - $\tilde\alpha_i = \bar\alpha + w_i(\hat\alpha_i-\bar\alpha)$, $w_i = \tau^2/(\tau^2+v_i)$
  - $v_i$는 $\hat\alpha_i$의 분산, $\tau^2$는 가게 간 실제 차이의 분산(적률법)이다.
  - 기록이 적은 가게일수록 전체 평균 쪽으로 당겨져 극단적인 예측을 막는다.
- **예측분포:**
  - $\ln(\text{매출}) \sim \mu + s\,t_{df}$, $s^2=\sigma^2+\mathrm{Var}(\tilde\alpha_i)+x^\top\mathrm{Var}(\hat\beta)x$
  - 화면에는 중앙값 $e^\mu$와 80% 예측구간을 보인다.
- **검증(표시 조건):**
  - 기록을 하나씩 빼고 다시 적합해 뺀 기록을 예측하는 교차검증(LOO)으로 80% 구간 적중률을 잰다.
  - 적중률이 80%와 통계적으로 다르면(정확 이항검정 $p<0.05$) 예측을 표시하지 않는다.
- **기준:** 내 매출 기록 3건 이상, 전체 기록 40건 이상, 가게 5곳 이상. 7일을 넘는 행사나 과거 기록이 없는 유형은 예측하지 않는다.

### ② 적자 확률 — 예측분포에서 정확 계산

- **적자 조건:** 순이익 $=$ 매출 $\times(1-c) - F < 0$ ⇔ $\ln(\text{매출}) < \ln\!\big(F/(1-c)\big)$
  - $F$: 참가비 + 내 평균 부대비용
  - $c$: 내 상품 원가율(판매액 가중)
- **확률:** $P(\text{적자}) = T_{df}\big((\ln(F/(1-c)) - \mu)/s\big)$
- 닫힌 형태로 정확히 계산되므로 몬테카를로 시뮬레이션은 쓰지 않는다.
- 원가가 입력되지 않으면 재료비를 제외한 기준이라고 화면에 표시한다.

### ⑤ 준비 수량 진단 — 뉴스벤더 최적 조건의 이항검정

- **문제 설정:** 당일 못 팔면 버리는 상품(음식·디저트)은 뉴스벤더 문제다.
  - 과소 준비 손실 $c_u = p - c$, 과잉 준비 손실 $c_o = c$
  - 최적 준비량은 $P(D\le Q^*) = (p-c)/p$를 만족한다.
  - 따라서 **최적이라면 품절 확률 $= c/p$**다.
- 이 조건은 수요 분포의 모양과 무관하고, 행사마다 수요가 달라도 성립한다. 그래서 수요 분포를 추정하지 않고 "품절 행사 수 ~ Bin(n, c/p)"를 **정확 이항검정**으로 확인한다. 상품 간에는 Holm 보정한다.
- **기준:** 상품별 8회 이상, 원가 입력 필수.
- **가정:**
  - 남은 상품의 잔존가치는 0이다.
  - 품절로 잃는 단골·평판 비용은 반영하지 않는다. 반영하면 최적 품절률은 조금 낮아진다.
  - 행사 간 품절 여부는 서로 독립이다.
- 수공예·패션 등 다시 팔 수 있는 상품은 전제가 맞지 않아 적용하지 않는다.
- 합성 데이터는 `판매량 = 준비량 × 비율`로 만들어져 실제 수요 과정이 아니므로, 이 진단 결과도 검증용으로만 본다.

### ⑦ 예상 매출 정확도 — 대응표본 t 구간

- 같은 행사의 $d=\ln(\text{실제}/\text{예상})$ 평균에 대해 $t_{n-1}$ 신뢰구간을 구한다. 구간이 0을 포함하지 않으면 "체계적 차이"로 판정한다.
- 짝이 5개 이상일 때만 표시한다.
- 목표 매출은 바라는 값이지 예측이 아니므로 쓰지 않는다.

### ④ 동종 셀러 대비 위치 — 서술 통계

- 같은 카테고리 가게들의 행사당 평균 매출 가운데 내 순위를 보인다.
- 비교 가게가 10곳 이상(각 3건 이상)이고 내 기록이 3건 이상일 때만 표시한다. 순위의 안정성과 개별 가게 식별 방지를 위한 기준이다.

## 4. 예상 질문과 답

- **"회귀 결과가 합성 데이터 가정을 다시 찾은 것 아닌가?"** — 맞다. 그래서 결과를 "발견"이 아니라 "알려진 효과를 복원하는 능력의 검증"으로 제시한다. 실제 셀러 기록이 쌓이면 같은 코드가 실제 효과를 추정한다.
- **"셀러 한 명당 기록이 몇 건 안 되는데 개인 맞춤이 되나?"** — 가게 효과를 경험적 베이즈로 축소 추정해 소표본 문제를 다룬다. 기록이 3건 미만이면 예측하지 않는다.
- **"예측구간을 믿을 근거는?"** — LOO 교차검증의 적중률을 이항검정해 통과할 때만 표시한다.
- **"요인이 여러 개면 하나쯤 우연히 유의하지 않나?"** — Holm 보정 후에만 "의미 있음"으로 표시한다.
- **"날씨가 매출을 줄인다는 인과 주장인가?"** — 아니다. 같은 가게 안의 연관성이며, 참가 선택 효과는 통제하지 못한다고 명시한다.
- **"뉴스벤더를 쓰려면 수요분포가 필요하지 않나?"** — 최적 품절확률 $c/p$라는 조건은 분포와 무관하게 성립한다. 그래서 분포를 추정하지 않고 이 조건 자체를 검정한다.
